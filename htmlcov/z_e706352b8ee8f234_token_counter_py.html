20class GoogleGenAITokenCounter: 

21 """ 

22 Counts input tokens for Gemini models with Google's token counting API. 

23 

24 Unlike local token counters, this counter sends the input to the `countTokens` endpoint of the Google Gen AI 

25 SDK, so the returned count includes the model-specific formatting Gemini applies to messages. 

26 

27 Inputs are assembled exactly as `GoogleGenAIChatGenerator` sends them: a leading system message becomes the 

28 system instruction and the remaining messages become the request contents. 

29 

30 ### Backend support for system instructions and tools 

31 

32 The Google Gen AI SDK only accepts a system instruction and tool schemas on `countTokens` when the client 

33 targets Vertex AI. On the Gemini Developer API, a leading system message is therefore measured as a user turn, 

34 which gives a close approximation rather than the exact count, and tools raise a `ValueError` instead of 

35 silently returning a count that omits their schemas. Counting plain messages works on either backend. 

36 

37 ## Usage Example: 

38 ```python 

39 from haystack.dataclasses import ChatMessage 

40 from haystack_integrations.token_counters.google_genai import GoogleGenAITokenCounter 

41 

42 counter = GoogleGenAITokenCounter("gemini-3.7-flash") 

43 messages = [ChatMessage.from_user("Hello, how are you?")] 

44 token_count = counter.count(messages) 

45 print(f"Token count: {token_count}") 

46 ``` 

47 """

101 def count(self, messages: list[ChatMessage], tools: ToolsType | None = None) -> int: 

102 """ 

103 Return the number of input tokens Gemini will use for the given messages and tools. 

104 

105 :param messages: The messages to measure. A leading system message is measured as the system instruction on 

106 Vertex AI and as a user turn on the Gemini Developer API, which cannot measure system instructions. 

107 :param tools: Tools whose schemas are sent alongside the messages, and so consume tokens too. 

108 :returns: The token count, or `0` when there is nothing to measure. 

109 :raises ValueError: If tools are passed while targeting the Gemini Developer API, which cannot measure them. 

110 """ 

111 if not messages and not tools: 

112 return 0 

113 

114 # Rejected before the client is built, so an unsupported request fails the same way with or without 

115 # credentials. 

116 if tools and self.api != "vertex": 

117 msg = ( 

118 "Counting tokens for tools is only supported when targeting Vertex AI, because the Google Gen AI SDK " 

119 'rejects them on the Gemini Developer API. Initialize this counter with api="vertex", or count only ' 

120 "the messages." 

121 ) 

122 raise ValueError(msg) 

123 

124 # Mirror how GoogleGenAIChatGenerator splits the request: a leading system message is sent separately. 

125 chat_messages = messages 

126 system_instruction = None 

127 if messages and messages[0].is_from(ChatRole.SYSTEM): 

128 system_instruction = messages[0].text or "" 

129 chat_messages = messages[1:]

131 contents: list[types.ContentUnion] = [_convert_message_to_google_genai_format(m) for m in chat_messages] 

132 config_params: dict[str, Any] = {}

138 # user turn. This is a close approximation, not the exact count.
