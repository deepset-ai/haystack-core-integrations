83class PresidioPIIHook: 

84 """ 

85 Detects personally identifiable information (PII) in an Agent's messages with Microsoft Presidio. 

86 

87 Register the same instance at `before_llm`, so PII never reaches the LLM provider, and at `after_run`, so the final 

88 reply returned to the user is checked too. The final reply is produced by the last LLM call, so no `before_llm` 

89 hook runs after it: 

90 

91 <!-- test-ignore --> 

92 ```python 

93 from haystack.components.agents import Agent 

94 from haystack.components.generators.chat import OpenAIChatGenerator 

95 from haystack.dataclasses import ChatMessage 

96 from haystack_integrations.hooks.presidio import PresidioPIIHook 

97 

98 pii_hook = PresidioPIIHook( 

99 entity_score_thresholds={"PERSON": 0.6}, 

100 entity_actions={"CREDIT_CARD": "block", "IBAN_CODE": "stop"}, 

101 ) 

102 agent = Agent( 

103 chat_generator=OpenAIChatGenerator(), 

104 hooks={"before_llm": [pii_hook], "after_run": [pii_hook]}, 

105 ) 

106 result = agent.run(messages=[ChatMessage.from_user("Hi, I'm John Smith from Berlin.")]) 

107 # The LLM receives: "Hi, I'm <PERSON> from <LOCATION>." 

108 ``` 

109 

110 Each run checks the messages it has not checked yet: user and assistant text and tool results. System messages, 

111 system reminders, tool-call arguments, reasoning, images, and files are not checked. Every detected entity maps to 

112 an action, and a message takes the strictest action among its entities: 

113 

114 - `"redact"` (default): Presidio's anonymizer replaces each entity with a placeholder such as `<PERSON>`. 

115 - `"block"`: The message's text is replaced with `block_message`. Mid-run, a system reminder is added telling the 

116 model the message was removed; once the run is exiting, the reply is replaced without a reminder. 

117 - `"stop"`: The message is redacted and the run stops before the next LLM call, with `exit_reason` set to 

118 `"pii_detected"`. 

119 

120 Hooks at the same hook point run in list order, and any hook listed before this one sees unredacted messages. 

121 List it first, for example ahead of a `CompactionHook` that summarizes the conversation with an LLM. To keep PII 

122 out of a `ToolResultOffloadHook` store, also register it first at `after_tool`: 

123 

124 <!-- test-ignore --> 

125 ```python 

126 hooks = { 

127 "after_tool": [pii_hook, offload_hook], 

128 "before_llm": [pii_hook, compaction_hook], 

129 "after_run": [pii_hook], 

130 } 

131 ``` 

132 

133 Limitations: 

134 

135 - When the Agent or its chat generator has a `streaming_callback`, the reply streams to the user before any hook 

136 runs, so PII in the reply cannot be stopped in that mode. 

137 - Because the model only sees placeholders, the tool-call arguments it writes contain placeholders too, so a tool 

138 that needs the real value (for example, an email address to send to) receives `<EMAIL_ADDRESS>`. 

139 - If the hook runs at `after_tool` and blocks the result of a tool in `exit_conditions`, the reminder becomes the 

140 Agent's last message. Read the tool result from `result["messages"]` instead of `result["last_message"]`. 

141 - After an `on_exit` hook keeps the run going, messages blocked later in the run get no reminder. 

142 

143 Each run records its decision on the hook's tracing span under `haystack.agent.hook.pii.*`: how many messages it 

144 checked, whether anything was found, the action taken, the count of each entity type, and whether Presidio failed. 

145 The checked and rewritten texts are recorded as content tags, so they are only emitted when content tracing is on. 

146 With content tracing on, traces contain raw PII: this hook's input tag holds the original text, and the Agent's own 

147 spans record messages before any hook redacts them. 

148 """ 

149 

150 allowed_hook_points: ClassVar[tuple[str, ...]] = ("before_run", "before_llm", "after_tool", "after_run")
